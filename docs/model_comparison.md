# FD001 模型对比实验

## 实验设置

- 数据集：NASA C-MAPSS FD001（训练集）。
- 划分方式：按发动机编号划分，编号 1--80 用于训练，81--100 用于验证。
- 特征：运行周期、3 个运行设置和 21 个传感器读数。
- 指标：MAE 与 RMSE，数值越低越好。

## 结果

| 模型 | MAE（cycles） | RMSE（cycles） |
| --- | ---: | ---: |
| Ridge | 42.38 | 53.13 |
| Random Forest | **34.13** | **47.97** |
| Histogram Gradient Boosting | 34.45 | 48.02 |

## 结论

Random Forest 在本次发动机级验证划分下同时取得最低 MAE 和 RMSE，因此保留为当前 RUL 预测主模型。Histogram Gradient Boosting 的结果接近，后续可结合超参数调优和更严格的验证策略继续比较。

## 注意事项

本实验只使用一个固定的发动机划分，结果用于原型阶段模型选择。后续应使用多次发动机级交叉验证或不同随机划分，以评估结果稳定性。

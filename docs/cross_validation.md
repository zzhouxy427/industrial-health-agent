# Random Forest 交叉验证实验

## 设置

- 数据集：NASA C-MAPSS FD001 训练集
- 模型：Random Forest Regressor
- 特征：运行周期、3 个运行设置、21 个传感器读数
- 验证方式：5 折发动机级 GroupKFold
- 原则：同一台发动机的所有周期只会出现在训练集或验证集之一，避免数据泄漏。

## 每折结果

| 折数  | MAE（cycles） | RMSE（cycles） |
| --- | -----------:| ------------:|
| 1   | 26.83       | 40.46        |
| 2   | 25.71       | 37.89        |
| 3   | 28.69       | 39.16        |
| 4   | 25.74       | 36.52        |
| 5   | 27.39       | 36.61        |

## 汇总

- MAE：26.87 ± 1.25 cycles
- RMSE：38.13 ± 1.69 cycles

## 结论

五个折次的误差波动较小，说明当前 Random Forest 模型在不同发动机分组上的表现相对稳定。后续将以该交叉验证结果作为超参数调优前的基线。

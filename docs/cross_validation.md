# Random Forest 交叉验证实验

## 设置

- 数据集：NASA C-MAPSS FD001 训练集
- 模型：Random Forest Regressor
- 特征：运行周期、3 个运行设置、21 个传感器读数
- 验证方式：5 折发动机级 GroupKFold
- 原则：同一台发动机的所有周期只会出现在训练集或验证集之一，避免数据泄漏。

## 每折结果

| 折数  | MAE（cycles） | RMSE（cycles） |
| --- | -----------:| ------------:|
| 1   | 27.25       | 40.73        |
| 2   | 25.96       | 38.65        |
| 3   | 25.25       | 36.06        |
| 4   | 28.75       | 38.80        |
| 5   | 24.67       | 33.61        |

## 汇总

- MAE：26.37 ± 1.64 cycles
- RMSE：37.57 ± 2.77 cycles

## 结论

五个折次的误差存在合理波动，说明评估结果需要以均值和标准差共同解读。当前生产特征选择基于原始特征与 3/5/10 周期滚动特征的发动机级对比；完整结果见 [temporal_feature_selection.md](temporal_feature_selection.md)。

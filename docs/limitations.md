# 模型局限与安全边界

## 数据与泛化限制

- **模拟数据限制**：FD001 为仿真数据，且只有单一工况和单一故障模式。真实设备可能同时受到载荷变化、环境、维护记录、传感器老化和多故障耦合影响。
- **训练/测试同源**：官方 FD001 测试集与训练集属于同一基准设置，不能说明模型能跨设备型号、跨工厂或跨工况泛化。
- **标签可得性差异**：实验阶段可以用 `RUL_FD001.txt` 计算误差；真实在线运行中未来失效时间不可见，不能展示或使用“真实 RUL”。

## 预测与阈值限制

- **预测区间仍有泛化边界**：P10–P90 先来自随机森林中各树预测的分位数，再由训练集独立发动机估计的 split conformal 偏移扩张。当前 FD001 官方测试集经验覆盖率为 86.0%（名义约 80%），但这一结果只覆盖单一模拟基准，不能解释为真实设备上的严格统计或安全保证。
- **阈值反映成本假设**：20 cycles 来自“漏报成本为误报 5 倍”的验证实验。不同业务、备件周期和安全等级应重新定义成本并重新校准。
- **点预测误差不可忽略**：官方 MAE 为 19.53 cycles，实际维护决策应考虑这一误差尺度和预测区间，而不是只看一个 RUL 数字。
- **发布门禁不是充分验证**：MAE/RMSE 门限只用于阻止相对当前 FD001 基线的明显退化；它不能证明没有偏差、泛化更好或满足真实安全/合规要求。

## 监控与诊断限制

- **PSI 不等同于模型失效**：PSI 只反映输入分布变化；偏移可能来自正常退化过程，也可能来自工况、数据采集或传感器校准变化。它应触发复核，而不是自动禁用模型。
- **数据质量检查有限**：当前检查缺失、重复、周期连续性和范围提示，无法发现所有物理传感器故障、单位变更或标签错误。
- **趋势规则是启发式的**：当前重点观察 sensor_4 和 sensor_11 的近期变化，不能替代故障机理分析。

## LLM 与自动化安全边界

- LLM 只能根据导出的 JSON 上下文和本地知识库总结，不能编造传感器值、篡改 RUL 或声明故障确定发生。
- 输出会检查人工复核、传感器趋势、预测区间和研究用途声明，并拒绝自动停机、立即维修等危险措辞。
- 系统只生成“人工复核优先级”；不连接设备控制系统，不自动下达维护或安全关键指令。

## 上线前仍需补充的工作

1. 使用真实、跨工况且带维护记录的数据重新训练与独立测试。
2. 在跨工况、跨设备的独立数据上重复检验预测区间覆盖率和校准稳定性。
3. 与领域专家共同定义风险成本、阈值、告警等级和人工复核流程。
4. 建立生产数据版本、模型版本、监控告警、回滚和权限控制机制。
5. 进行针对具体行业的安全、合规和可靠性评审。

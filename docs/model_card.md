# Model Card：Industrial Health Agent RUL 模型

## 1. 模型标识与版本

- 模型版本：`rf-fd001-raw-conformal-v3`
- 任务：基于发动机当前运行周期、3 个运行设置和 21 个传感器读数，估计剩余寿命（RUL，单位为 cycles）。
- 主模型：`RandomForestRegressor`，`n_estimators=200`、`max_depth=20`、`min_samples_leaf=4`、`max_features=1.0`、`random_state=42`。
- 输出：RUL 点预测、经 split conformal 扩张的 P10–P90 区间、树预测标准差，以及 `critical` / `review` / `monitor` 人工复核优先级。

该模型版本、特征集、超参数和评估摘要会被写入诊断上下文和审计日志，便于追溯某次结论使用的模型配置。

## 2. 预期用途

该原型用于研究和教学：演示如何把寿命预测、区间不确定性、数据质量、输入漂移、趋势规则、知识库建议和人工复核组织成一个可追溯的诊断流程。

适合：

- C-MAPSS FD001 上的算法实验与工程流程复现；
- 机器学习模型监控、预测不确定性和风险队列的教学演示；
- 作为迁移到真实工业数据前的原型参考。

不适合：

- 直接控制设备、自动停机、自动维修或安全关键决策；
- 声称真实发动机将在某个具体周期失效；
- 未经重新验证就迁移到多工况、多故障模式或不同设备型号。

## 3. 数据与特征

- 数据集：NASA C-MAPSS FD001 仿真数据。
- FD001 特点：单一工况、单一故障模式；训练集 100 台发动机、官方测试集 100 台发动机。
- 生产特征集：`cycle`、`op_setting_1` 至 `op_setting_3`、`sensor_1` 至 `sensor_21`。
- 标签：训练轨迹末端定义为 RUL=0，向前逐周期递增。

原始数据、派生产物和本地密钥均不提交到 Git。完整准备步骤见项目根目录 [README](../README.md)。

## 4. 评估证据

| 指标 | 结果 | 说明 |
| --- | ---: | --- |
| 官方 FD001 MAE | 19.53 cycles | 训练集拟合后，仅对官方测试集每台发动机最后一个周期评估 |
| 官方 FD001 RMSE | 26.10 cycles | 同上 |
| 5 折发动机级 CV MAE | 26.37 ± 1.64 cycles | `GroupKFold` 按发动机分组，避免同一轨迹泄漏 |
| 5 折发动机级 CV RMSE | 37.57 ± 2.77 cycles | 同上 |
| 校准后区间实际覆盖率 | 86.0% | 名义约 80%，使用训练集独立发动机的 split conformal 校准 |
| 告警提前量回测 | 19/20 台临界区前触发复核；中位提前 21.5 cycles | 保留发动机轨迹回测，非真实生产承诺 |
| 人工复核队列离线召回率 | 93.8% | 代价是精确率 71.4%；仅 `critical` 点预测的召回率为 62.5% |

完整实验设置和结果解释见 [experiment_report.md](experiment_report.md)。

## 5. 不确定性与人工复核

基础区间来自随机森林中每棵树输出的 P10–P90 分位数。系统使用训练集中独立发动机的模拟观测点估计 split conformal 双侧扩张偏移；当前偏移为 6.33 cycles，RUL 下界被裁剪为不小于 0。

风险队列只决定人工复核优先级：

| 优先级 | 条件 | 含义 |
| --- | --- | --- |
| `critical` | 点预测 RUL ≤ 20 | 优先人工复核 |
| `review` | 点预测高于 20，但区间下界 ≤ 20 | 不确定性触及阈值，建议复核 |
| `monitor` | 其他 | 持续监测 |

阈值来自 FD001 模拟验证中的成本假设，绝不是自动停机或维护阈值。

在官方测试集离线实验中，`critical + review` 队列识别出 16 台真实临界设备中的 15 台（召回率 93.8%），同时送入 6 台误报设备复核。该权衡说明区间的价值在于减少漏报，而不是替代人工判断。

## 6. 监控与已知风险

- **数据质量**：检查缺失、重复周期、周期不连续和超出训练 1%–99% 范围的输入；无法发现所有物理传感器故障。
- **输入漂移**：按训练集分位数计算 PSI；受控偏置压力测试验证了显式注入的传感器/工况偏移能够被标记，但 PSI 不等同于模型失效。
- **性能门禁**：本地完整流水线要求官方 FD001 MAE ≤ 22、RMSE ≤ 30，并要求离线人工复核队列召回率 ≥ 90%，以防明显回归或漏报增加；它不是充分泛化或安全验证。
- **模型快照**：每次本地流水线导出预测时，保存 `rul_model.joblib` 与含版本、特征、区间校准信息和 SHA-256 指纹的清单。模型二进制仅可从受信任的本地产物加载，不能接受用户上传文件。
- **LLM 辅助**：只可总结结构化证据和本地知识库，输出经安全校验，不得生成自动维修或安全关键命令。

## 7. 变更与发布控制

修改特征、超参数、训练逻辑、区间逻辑或风险阈值后，至少应：

1. 运行 `python -m pytest -q` 与 `python -m compileall -q src tests`；
2. 运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run_full_pipeline.ps1`；
3. 检查性能门禁、区间覆盖率、告警提前量和漂移报告；
4. 更新本 Model Card、实验报告、版本号和审计元数据；
5. 在独立、跨工况且有领域专家审核的数据上重新验证，才考虑任何进一步应用。

发布前具体操作见 [release_checklist.md](release_checklist.md)。

# 时间窗口特征选择实验

## 问题

滚动均值和标准差常被用于设备退化建模，但“加入更多时间窗口特征一定更好”并不成立。为了避免依据单次留出集或官方测试集挑选特征，本实验以发动机为分组进行 5 折 `GroupKFold`，比较原始特征与不同长度的因果滚动窗口。

## 共同设置

- 数据：NASA C-MAPSS FD001 训练集；
- 模型：调优后的 `RandomForestRegressor`；
- 原始特征：运行周期、3 个运行设置、21 个传感器读数；
- 滚动特征：在同一发动机内计算各传感器的滚动均值和标准差，窗口不跨发动机边界；
- 验证：5 折发动机级 `GroupKFold`；指标为 MAE 与 RMSE。

## 结果

通过以下命令复现：

```powershell
python src\cross_validate_temporal_windows.py
```

| 特征集 | 窗口 | MAE（cycles） | RMSE（cycles） |
| --- | ---: | ---: | ---: |
| 原始特征 | — | **26.37 ± 1.64** | **37.57 ± 2.77** |
| 滚动特征 | 3 | 26.49 ± 1.50 | 38.09 ± 2.25 |
| 滚动特征 | 5 | 26.73 ± 1.44 | 38.63 ± 2.06 |
| 滚动特征 | 10 | 27.33 ± 1.94 | 39.37 ± 2.46 |

## 决策

原始特征在 MAE 与 RMSE 均值上均为最优，因此当前生产推理统一使用原始特征。特征定义集中在 `src/feature_config.py`，并由预测导出、官方测试评估、阈值校准与交叉验证共同调用，避免实验脚本与线上诊断使用不同特征集。

滚动窗口实现仍保留在 `src/train_engineered.py`，作为后续时序特征实验的基线。该实验仅说明在当前 FD001、当前模型与该验证方案下原始特征更合适，不能推导到所有设备或数据集。
